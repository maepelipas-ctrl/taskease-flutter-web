# SimpleCare Appointment System

## Summary
SimpleCare is a small clinic appointment-system starter project created for IT 110 Laboratory Activity 8. This checkpoint demonstrates a Flutter Web application with a Home screen and a Login placeholder.

## Current technology stack
- Flutter Web and Dart: implemented for the starter interface.
- REST API: planned only; no backend endpoints are implemented in Activity 8.
- PostgreSQL: planned only; no database connection is implemented in Activity 8.
- Git and GitHub: used for version control and the first project checkpoint.

## Source structure
- `lib/main.dart`: application entry point.
- `lib/app.dart`: app theme and named routes.
- `lib/screens/`: Home and Login pages.
- `lib/widgets/`: reusable button and text-field widgets.
- `lib/services/`: reserved for future API integration.
- `lib/models/`: reserved for data models.
- `lib/routes/`: reserved for routing helpers.
- `lib/constants/`: reserved for shared constants.

## Run locally
Install Flutter and Google Chrome, then run these commands from this directory:

```bash
flutter pub get
flutter run -d chrome
```
